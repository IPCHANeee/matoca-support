1. はじめに

本ポリシーは、個人開発者「Matoca」（以下「当方」）が提供するモバイルアプリ「Matoca」（以下「本アプリ」）における個人情報の取り扱いを説明します。本アプリはローカルファースト設計であり、既定では利用者のデータを端末内にのみ暗号化して保存します。クラウド同期（後述）は利用者が明示的にログインした場合にのみ有効になる任意機能です。

2. 取得・保存する情報

種別内容保存場所いつ
予定・タスクタイトル、メモ、日時、カテゴリ、完了状態端末内（暗号化DB）利用者が作成/取り込み時
アカウント情報メールアドレス、パスワードクラウド（Supabase Auth）クラウド同期にログインした場合のみ
外部連携トークンGoogle 等のアクセストークン端末内（OSセキュア領域）利用者が外部連携を許可した場合のみ
設定言語、外観、通知、週の始まり等端末内利用者が変更時
連絡先（現在は不使用）——

本アプリは、広告ID・行動履歴・位置情報の収集を行いません。

3. 保存方法とセキュリティ

  • 端末内データは SQLite を SQLCipher で暗号化して保存します。暗号化キーは端末のKeychain（iOS）/ Keystore（Android） に保管し、アプリのコードには埋め込みません。
  • 外部連携トークンは端末内のセキュア領域にのみ保存し、当方サーバー/クラウドへ送信しません。
  • クラウド同期を有効にした場合、予定/タスクは Supabase 上の各利用者専用の領域に保存され、行レベルセキュリティ（RLS）により本人のみアクセス可能です。通信は TLS1.2以上で暗号化します。
  • パスワードは Supabase Auth によってサーバー側でハッシュ化して管理され、当方は平文を保存しません。
  • 任意で起動時のOS認証（生体認証/パスコード）による閲覧ロックを利用できます。

4. 第三者への提供・外部サービス

本アプリは、利用者が明示的に連携を許可した場合に限り、以下の外部サービスと通信します。

  • Supabase（クラウド同期のバックエンド。予定/タスク・アカウント情報）
  • Google（Calendar / Tasks）（利用者のカレンダー/タスクの読み取り取り込み）
  • （今後）Microsoft Outlook / Todoist / TickTick 等

各サービスの取り扱いは、それぞれの提供元のプライバシーポリシーに従います。当方は利用者データを広告目的で第三者に販売・提供しません。

4-1. Google ユーザーデータの取り扱い（Limited Use）

本アプリが Google API から取得した情報の使用および他アプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定的な使用（Limited Use）の要件を含む）に準拠します。具体的には次のとおりです。

  • 取得する情報: 利用者が連携を許可した場合に限り、Google カレンダーの予定（calendar.readonly）と Google ToDo リストのタスク（tasks.readonly）を読み取り専用で取得します。予定やタスクの作成・変更・削除は行いません。
  • 使用目的: 取得した予定/タスクを、本アプリの一覧・カレンダー表示に統合して利用者本人に表示するためだけに使用します。
  • 保存場所: 取得したデータは利用者の端末内の暗号化データベースにのみ保存します。アクセストークンは端末のセキュア領域（Keychain / Keystore）にのみ保存し、当方のサーバーを含むいかなるバックエンドにも送信しません。
  • 第三者提供: Google から取得した情報を、第三者へ販売・譲渡・提供することはありません。広告・プロファイリング・AIモデルの学習には一切使用しません。
  • 人による閲覧: 当方の開発者がこれらのデータを閲覧することはありません（利用者の明示的な同意に基づく不具合調査、法令上の要求、セキュリティ上の必要がある場合を除きます）。
  • 連携の解除: アプリ内で連携を解除すると、端末内のアクセストークンは直ちに削除されます。 Google アカウント側からも アカウントの「サードパーティ製アプリとサービス」でいつでもアクセス権を取り消せます。

5. 保存期間・削除

  • 削除した予定/タスクはソフト削除され、30日後に端末およびクラウドから物理的に削除されます。
  • 利用者はアプリ内でデータを削除できます。クラウド上のアカウント/データの削除を希望する場合は matoca.app@gmail.com までご連絡ください。

6. 利用者の権利

利用者は、自己の個人情報について、開示・訂正・削除・利用停止を求めることができます。ご要望はmatoca.app@gmail.com までご連絡ください。

7. 子どものプライバシー

本アプリは 13歳未満の子どもを対象としていません。

8. 変更

本ポリシーを変更する場合、本アプリ内または配布ページ（App Store等）で告知します。

9. 準拠法

本ポリシーおよび本アプリの利用は、日本法に準拠します。
